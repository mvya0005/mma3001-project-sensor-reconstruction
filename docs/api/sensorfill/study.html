sensorfill.study

Study configuration shared by all notebooks: sensors, splits and occupancy proxy.

Keeping these choices in one place guarantees that every notebook trains, tunes and tests on exactly the same periods.

Design decisions (justified in notebook 00):

  • Primary sensor 6012002000869 (Building 60, G.38 Compactus upper): 15 weeks of 10-min data, only isolated 1-2 sample dropouts, so long artificial gaps have clean ground truth.
  • Chronological split (no shuffling, so no future information leaks into training): train 29 Feb - 30 Apr 2024, validation 1 - 21 May, test 22 May - 14 Jun. Validation is used for every model/parameter choice; the test period is touched once, in notebook 06.
  • Occupancy proxy: the sum of the four floor spaces that report throughout the study period. None of them is confirmed to be the same room as the CO2 sensor, so the proxy represents building activity, not the room's occupants. The fifth space (3e5a14df) only starts reporting in May, so it would be missing for the whole training period.
  • Secondary sensor 6012002000326 (location not listed): a different room and period (Sep 2025 - Apr 2026) used only as an external generalisation test, without occupancy (its CO2 does not correlate with any occupancy space).

 57@dataclass
 58class Study:
 59    """One target variable of one sensor, with splits and context.
 60
 61    Attributes:
 62        y: Target series (NaN = missing) on the 10-min grid.
 63        ts: Timestamps.
 64        occ: Occupancy proxy [persons] or None.
 65        split: Array of ``"train"``, ``"val"`` or ``"test"`` labels.
 66        variable: Target name (e.g. ``"co2"``).
 67        unit: Target unit.
 68    """
 69
 70    y: np.ndarray
 71    ts: pd.DatetimeIndex
 72    occ: np.ndarray | None
 73    split: np.ndarray
 74    variable: str
 75    unit: str
 76
 77    def part(self, name: str):
 78        """Return the data of one split.
 79
 80        Args:
 81            name: ``"train"``, ``"val"`` or ``"test"``.
 82
 83        Returns:
 84            ``(y, ts, occ)`` restricted to that split (``occ`` is None when
 85            the study has no occupancy proxy).
 86
 87        Example:
 88            >>> st = Study(np.arange(4.0), pd.date_range("2024-01-01", periods=4, freq="10min"),
 89            ...            None, np.array(["train", "train", "val", "test"]), "co2", "ppm")
 90            >>> st.part("train")[0].tolist()
 91            [0.0, 1.0]
 92        """
 93        m = self.split == name
 94        return self.y[m], self.ts[m], None if self.occ is None else self.occ[m]
 95
 96    @property
 97    def train_profile(self) -> pd.Series:
 98        """Typical-day profile computed on the training period only (no leakage).
 99
100        Returns:
101            Median value per (weekend flag, minute of day), as returned by
102            :func:`sensorfill.interpolation.daily_profile`.
103        """
104        y, ts, _ = self.part("train")
105        return daily_profile(y, ts)
106
107    def profile_values(self, ts) -> np.ndarray:
108        """Evaluate :attr:`train_profile` on arbitrary timestamps.
109
110        Args:
111            ts: Timestamps (any array-like accepted by ``pd.DatetimeIndex``).
112
113        Returns:
114            The typical-day value for each timestamp (NaN for a time of day
115            never seen in training).
116        """
117        ts = pd.DatetimeIndex(ts)
118        keys = pd.MultiIndex.from_arrays([ts.dayofweek >= 5, ts.hour * 60 + ts.minute])
119        return self.train_profile.reindex(keys).to_numpy()
120
121    @property
122    def level_ref(self) -> float:
123        """Median of the training target (reference level for ML features).
124
125        Returns:
126            ``nanmedian`` of the training-split target, in the target's units.
127        """
128        return float(np.nanmedian(self.part("train")[0]))

131def load_study(processed: str | Path = "data/processed", variable: str = "co2", sensor: str = PRIMARY_SENSOR) -> Study:
132    """Load a processed sensor series with its split labels and occupancy proxy.
133
134    Args:
135        processed: Folder written by ``scripts/preprocess.py``.
136        variable: ``"co2"``, ``"temp"``, ``"rh"`` or ``"pressure"``.
137        sensor: Sensor id.
138
139    Returns:
140        A :class:`Study`. For the secondary sensor, ``occ`` is None and the
141        whole series is labelled ``"test"``.
142
143    Raises:
144        FileNotFoundError: If preprocessing has not been run.
145
146    Example:
147        >>> st = load_study("data/processed", "co2")  # doctest: +SKIP
148        >>> st.unit, sorted(set(st.split))  # doctest: +SKIP
149        ('ppm', ['test', 'train', 'val'])
150    """
151    from .data import UNITS
152
153    processed = Path(processed)
154    f = processed / f"env_{sensor}.parquet"
155    if not f.exists():
156        raise FileNotFoundError(f"{f} not found - run scripts/preprocess.py (or notebook 00) first")
157    env = pd.read_parquet(f)
158    ts = pd.DatetimeIndex(env.index)
159    y = env[variable].to_numpy(dtype=float)
160    if sensor == PRIMARY_SENSOR:
161        occ_df = pd.read_parquet(processed / "occupancy.parquet").reindex(ts)
162        occ = occ_df[OCC_PROXY_SPACES].sum(axis=1, min_count=len(OCC_PROXY_SPACES)).to_numpy()
163        split = np.where(ts < TRAIN_END, "train", np.where(ts < VAL_END, "val", "test"))
164    else:
165        occ = None
166        split = np.full(len(ts), "test")
167    return Study(y, ts, occ, split, variable, UNITS.get(variable, ""))
